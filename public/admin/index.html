Save often. Publish together.

  1. Products: add a product, edit its English, Macedonian and Albanian text, upload photos, or delete an entry. Save it in the editor.
  2. Saving is not a live website update. The CMS “Publish” button saves to GitHub. Your current public website stays unchanged.
  3. Ready to go live? Open PUBLISH ALL, increase the release number by 1, then save. All saved changes are published together in one Netlify deployment.
  4. Check Netlify: wait for the deployment to succeed, then review the website. An error does not erase the previous live version.

First-time setup

The content editor requires the GitHub repository and Netlify OAuth configuration in the included setup guide. A GitHub connection in ChatGPT does not configure website login automatically.

Keep original image backups. Upload WebP/JPEG/PNG under 1 MB where possible. Confirm supplier photo permission and product availability before release. Never upload passwords, client lists or private artwork to the public image folder.
