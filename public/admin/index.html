Products and categories.

  1. One product: open Products and use the existing form. Editing and deleting work as before.
  2. Categories: open Categories to add, translate, reorder or rename catalogue filters. Use a stable lowercase URL ID such as wedding-invitations.
  3. Many products: download the Excel template, complete Products, and add each product colour to Colours. The category column must contain an existing category URL ID.
  4. New photos: put all referenced photos in one ZIP. Keep it flat—no folders—and use exactly the same filenames as in Excel.
  5. Import: open BULK IMPORT, create an entry, upload the XLSX and optional ZIP, leave status as Pending, then save.
  6. Review: after GitHub finishes, refresh the editor. The import entry shows Completed or Failed with a report; successful products appear under Products.

Important: use “Create only” for normal imports. “Create + update” may replace existing products and images with matching IDs or filenames.

За повеќе производи: пополни го Excel шаблонот, стави ги новите слики во еден ZIP, потоа отвори „МАСОВЕН ВНЕС“. Постоечкиот рачен начин останува ист.

Për shumë produkte: plotëso shabllonin Excel, vendosi fotot e reja në një ZIP, pastaj hap “IMPORT MASIV”. Mënyra ekzistuese manuale mbetet e njëjtë.

Save often. Publish together.

  1. Saving is not a live website update. Manual edits, categories and Excel imports are saved to GitHub while the public website stays unchanged.
  2. Ready to go live? Open PUBLISH ALL, increase the release number by 1, then save. All saved changes are published together in one Netlify deployment.
  3. Check Netlify: wait for success, then review the website. An error does not erase the previous live version.

Не се објавува секој производ одделно. Зачувај ги измените, потоа зголеми го бројот во „ОБЈАВИ СÈ“ за едно заедничко објавување.

Ruaj ndryshimet, pastaj rrit numrin te “PUBLIKO” për t’i publikuar të gjitha së bashku.

Safety

Keep original image backups. Upload WebP/JPEG/PNG under 1 MB where possible. Confirm supplier photo permission and availability before release. Never upload passwords, client lists or private artwork.
